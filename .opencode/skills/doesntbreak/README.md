# doesntbreak — skill vendida en este repo

Skill de diseño responsive mobile-first (320px+): UI que no se rompe en pantallas chicas, sin scroll horizontal, tailwind-aware, con modo de revisión de código existente.

## Origen y licencia

- **Fuente**: https://github.com/Kyaa-A/doesntbreak (autor: Asnari / Kyaa-A)
- **Licencia**: MIT, Copyright (c) 2026 Asnari (Kyaa-A)
- **Versión vendida**: `skills/doesntbreak/` del commit `main` (2026). Solo el contenido del skill (`SKILL.md` + `references/patterns.md`), **sin** hooks ni scripts del plugin (el update-check del repo se dejó fuera a propósito: no hace falta actividad de red en esta instalación).
- **Adaptación local**: se añadió la sección 13 en `references/patterns.md` con los tokens/patrones propios del proyecto Riverside Tenis (paleta, breakpoints, `Navigation.tsx`, clases de `globals.css`, safe-area). El resto del contenido está intacto.

## Instalación como "plain skill"

Copia directa de la carpeta al directorio de skills de opencode (`.opencode/skills/doesntbreak/`). Se descubre automáticamente por el campo `description` de `SKILL.md`; se activa al escribir/revisar layout web, aunque el usuario no diga "responsive".
