Manual de la profesora · Riverside Tenis

Guía de uso y reglas del sistema de gestión de clases de tenis, pensada para la profesora y administradora del sistema.

1. Introducción

El sistema administra clases de tenis, inscripciones de alumnos y deudas. Es una aplicación web responsive (diseñada primero para celular) accesible desde el navegador del teléfono, la tablet o la computadora.

¿Qué se puede hacer?

  • Administrar la agenda de clases (día y semana).
  • Crear plantillas de clases recurrentes y generar los meses automáticamente.
  • Crear clases abiertas/rotativas y clases extras con postulación de alumnos.
  • Inscribir, mover y quitar alumnos de las clases.
  • Controlar deudas por alumno y registrar pagos (individual o por lote).
  • Dar a cada alumno su propio acceso para ver sus clases y su saldo.

Los 3 tipos de usuario

Admin — acceso total, todos los módulos. Al entrar va a su panel.

Profesora — mismo alcance que admin en todos los módulos (tablero, alumnos, plantillas, facturación, pagos…). Es el rol de uso diario.

Alumno — solo su vista personal: sus clases, su saldo, su perfil y postularse a clases disponibles.

Acceso al sistema

Para entrar, cada persona usa su email y contraseña en la pantalla de ingreso. Las cuentas las crea la profesora desde Alumnos (o el admin).

Nota: las contraseñas son personales de cada usuario y no se publican en este manual. La profesora define las contraseñas al crear cada cuenta.

2. Manual de uso · Profesora / Admin

Login y panel central

Ingresás con tu email y contraseña. Si sos profesora caés directo al Tablero; si sos admin, a tu Panel. Desde el panel hay tarjetas de acceso a cada módulo:

Tablero Plantillas Instancias Clases Abiertas Alumnos Facturación Pagos

Barra de navegación persistente: en todas las páginas hay una barra que te permite moverte sin volver al panel. En celular es una barra inferior fija con los módulos principales (Tablero, Clases Abiertas, Facturación, Pagos) y un botón Menú que despliega el resto (Plantillas, Instancias, Alumnos, Mi Perfil). En computadora es una barra superior con todos los enlaces, tu nombre y el botón Salir.

Si en algún momento vas a una página sin permiso, el sistema te redirige automáticamente a la vista correcta.

Tablero (vista diaria y semanal)

Es la pantalla principal de trabajo. Muestra las clases del día con la hora, la modalidad, el nivel (con un chip de color: principiante rojo, intermedio verde, avanzado ámbar), el profesor/a y el cupo ocupado (ej: 2/4).

  • Día / Semana: botón para alternar entre las dos vistas. En el celular podés pasar de día deslizando el dedo (swipe).
  • Navegar fechas: flechas ◀ ▶, botón Hoy y Volver a hoy.
  • Abrir una clase: tocá la clase → se abre un panel inferior con opciones:
    • Ver alumnos (n/m): lista con el nivel de cada uno. Junto a cada alumno, botón Quitar (te pide confirmación).
    • + Agregar alumno: elegís un alumno de la lista y tocás Inscribir Alumno.
RestricciónNo se puede inscribir a una clase que ya tiene el cupo lleno desde el tablero: el sistema avisa "Cupo máximo alcanzado". Las clases canceladas se ven grises y desvanecidas.

Plantillas (clases recurrentes)

Una plantilla define una clase que se repite todas las semanas (día, horario, nivel, modalidad, profesor/a, cupo y precio por clase). Con las plantillas el sistema genera las instancias del mes.

  • + Nueva Plantilla: elegís día de la semana, modalidad (Fija / Extra / Abierta), hora inicio/fin, nivel, profesor/a, cupo máximo y precio por clase. Al crearla, el sistema genera las instancias del mes actual automáticamente.
  • La mensualidad = precio por clase × cantidad de clases del mes. Ej: $10 por clase y 4 clases en el mes → $40. El formulario aclara este cálculo.
  • ¿Fechas ya pasadas del mes? Si creás una plantilla cuando el mes ya empezó, el sistema te pregunta si querés generar también las fechas pasadas de ese mes o solo las futuras.
  • Editar: cambiás los datos de la plantilla y el sistema actualiza o regenera las instancias futuras.
  • Desactivar: la plantilla deja de generar clases nuevas y las instancias futuras quedan canceladas (como historial, no se borran).
  • Activar: vuelve a generar las instancias del mes.
Reglas
  • No se pueden crear dos plantillas activas el mismo día en horarios que se superpongan: el sistema lo rechaza con "Conflicto de horario".
  • La hora de inicio debe ser anterior a la hora de fin.
  • Los niveles: Principiante, Intermedio, Avanzado.

Instancias (las clases concretas de cada mes)

Las instancias son cada clase real (una fecha concreta). Se generan en lote desde las plantillas activas.

  • ⚙ Generar Mes: crea todas las instancias del mes mostrado para las plantillas fijas activas. Es seguro repetirlo: no duplica clases. Si regenerás el mes en curso, también pregunta si querés incluir las fechas ya pasadas.
  • Navegación de mes: flechas ◀ ▶ y el mes en pantalla.
  • Cada clase muestra horario, modalidad, nivel (chip de color), profesor/a, cupo, precio y estado (Programada o Cancelada).
  • Alumnos: cada clase indica "Alumnos: N/M" y debajo la lista de los nombres de los alumnos inscriptos (o "Sin alumnos").

Clases abiertas / rotativas y clases extras

Son clases puntuales (una fecha) a las que los alumnos se postulan y la profesora acepta o rechaza.

  • + Nueva Clase: elegís modalidad (Abierta/Rotativa o Extra), fecha, nivel, profesor/a, horario, cupo y precio. Si elegís Extra, el sistema sugiere un precio del 50% de la clase habitual.
  • Indicador de postulaciones: cada tarjeta muestra un badge ámbar "N candidatos" si hay postulaciones pendientes y la clase tiene cupo libre, o un badge gris "N en lista de espera" si la clase está llena. Sin pendientes, no aparece ningún badge.
  • Candidatos: cada clase muestra las postulaciones recibidas con el alumno, su nivel y su deuda neta (deuda − saldo a favor; si tiene saldo a favor se muestra en verde). Para cada postulación pendiente tenés tres acciones:
    • Aceptar — el alumno ocupa un cupo de la clase.
    • Rechazar — pasa a la lista de espera.
    • Forzar — aceptación por excepción aunque haya deuda o cupo lleno (permite superar el cupo).
  • Asistencia: por clase, marcás quién asistió y quién no, y guardás. En clases abiertas/extras, marcar que asistió genera la deuda de esa clase.
  • Editar / Eliminar: modificar datos o borrar la clase (pide confirmación).
¿Cuándo cobra un alumno de clase abierta/extra?Por asistencia: solo se le genera la deuda si vino. Si se anota pero no asiste, no debe nada por esa clase.

Alumnos

  • + Nuevo Alumno: email, contraseña (se la pasás al alumno para que entre), nombre, teléfono y nivel.
  • Editar: cambiar nombre, teléfono o nivel de un alumno.
  • Cambiar contraseña: al editar podés cargar una nueva contraseña para el alumno (sin pedirle la actual) — útil cuando pierde el acceso. Si la dejás vacía, la contraseña no cambia.
  • Alerta al cambiar nivel: si cambiás el nivel, el sistema informa las clases futuras (desde hoy) donde el alumno queda con nivel discrepante. Es solo un aviso: no modifica nada.
  • Desactivar / Activar: un alumno desactivado no puede ingresar al sistema (su estado se ve en rojo/verde).

Facturación (deuda mensual de clases fijas)

Las clases fijas se cobran por mensualidad: el alumno debe el mes completo asista o no (ocupó cupo). El sistema calcula la deuda de forma semi-automática.

  1. Elegí el mes con el selector de mes. El sistema muestra el estado del ciclo del mes (Abierto / Cerrado / No abierto).
  2. Revisá la tabla "Deuda propuesta (revisá antes de generar)". Por alumno verás:
    • la cuenta "N clases × $precio = total" del mes,
    • el botón "Ver clases" que despliega el detalle de cada clase (fecha, hora, precio individual),
    • un aviso si el alumno se inscribió a mitad de mes ("Inscripción: 15/08"),
    • el estado Generada (fondo verde) o Pendiente (fondo ámbar).
  3. Arriba de la tabla están los totales globales del mes: total a cobrar, total ya pagado y cantidad de alumnos con deuda.
  4. Generar deudas: crea la deuda de mensualidad de ese mes para todos los alumnos de clases fijas. No duplica: si un alumno ya tiene deuda de ese mes, la saltea.
  5. Abrir mes: cierra los meses anteriores y abre el mes nuevo. Al abrirlo se listan los alumnos con deuda sin pagar.
  6. En la tabla de deudores se ve por alumno: Monto total, Pagado, Saldo restante y Saldo a favor.
  7. Liberar cupos: para un alumno deudor, lo saca de todas las clases fijas del mes. Sus deudas del mes quedan pendientes: revisalas y ajustá/cobrá aparte.
ImportanteSi inscribís a un alumno en una clase fija a mitad de mes, el sistema le genera la deuda de mensualidad en ese momento (no hace falta esperar a "Generar deudas").

Pagos

  • Pago individual: alumno, monto (mayor a 0), fecha y nota opcional. Al elegir el alumno se muestra su deuda neta y su saldo a favor. El pago se aplica a la deuda pendiente más antigua del alumno.
  • Pago por lote: marcás varios alumnos y ponés un monto por alumno (el mismo para todos), fecha y nota. Registra todos juntos.
  • Resumen global por fecha: todos los pagos agrupados por día, con el total de cada día y los montos por alumno.
Pago parcial y saldo a favorSi el monto es menor a la deuda, la deuda queda parcial y sigue pendiente lo que falta. Si pagás de más, el excedente queda como saldo a favor del alumno (se ve en verde) y se aplica automáticamente a su próxima deuda. La profe también puede usarlo como pago manual.

3. Manual de uso · Alumno

El alumno entra con su email y contraseña y cae directo a Mis clases, donde ve todo su mundo en una sola página:

  • Mi Deuda: el saldo neto arriba (deuda − saldo a favor). Si debés se muestra en rojo; si tenés saldo a favor, en verde "a favor". Al tocarlo se abre el detalle:
    • Desglose por mes: cada deuda con su tipo (Mensualidad / Clase extra / Clase abierta), el monto, lo pagado y el saldo.
    • Historial de pagos: fecha, monto y nota de cada pago registrado.
  • Mis Clases: tus clases (fijas, abiertas aceptadas y extras) con día, horario, nivel (chip de color), modalidad y profesora.
  • Mi Perfil: tu página de perfil, enlazada desde la barra de navegación. Podés editar nombre y teléfono y cambiar tu contraseña (actual + nueva + confirmar). El email (tu login) y el nivel son solo lectura: los maneja la profe.
  • Clases Disponibles: las clases abiertas/rotativas y extras a las que te podés anotar. Cada tarjeta muestra fecha, horario, nivel, profesora, precio y cupo (X/Y).
    • Postularme: envía tu solicitud a la profesora.
    • Estado de tu postulación: Postulado (Pendiente) · Inscripto · Lista de espera · Lleno.
    • Cancelar: podés cancelar tu postulación mientras esté pendiente.
Regla: deuda pendienteSi tu deuda neta (deuda − saldo a favor) es mayor a cero, no podés postularte a clases disponibles. Si tu saldo a favor cubre tu deuda, podés postularte con normalidad. Consultá a la profesora para regularizar el pago (o para que autorice la excepción).

4. Reglas y restricciones de las acciones

Reglas de negocio

Deuda como condición de ingreso

  • Se evalúa la deuda neta = deuda pendiente − saldo a favor. Si es mayor a cero, el alumno no puede postularse a clases disponibles.
  • Un alumno con saldo a favor que cubra su deuda no queda bloqueado (puede postularse).
  • La profesora tiene dos excepciones: Forzar en la postulación (acepta aunque haya deuda o cupo lleno) y aceptar con override desde candidatos.

Cupos y lista de espera

  • Clase llena al momento de postularse → el alumno queda directo en lista de espera.
  • Al aceptar, se vuelve a verificar el cupo: si se llenó, pasa a lista de espera automáticamente.
  • Forzar / override puede superar el cupo máximo.
  • Inscripción directa desde el tablero con cupo lleno → rechazada ("Cupo máximo alcanzado").
  • No se permiten inscriptos duplicados en la misma clase (un mismo alumno no aparece dos veces).

Cómo se genera la deuda

  • Clase fija (mensualidad): al inscribir a un alumno se le genera la deuda de ese mes de inmediato; y la profe puede generarla en lote desde Facturación. Se debe el mes completo, asista o no.
  • Clase abierta / extra: al marcar asistencia "asistió" se le genera la deuda de esa clase (tipo clase_abierta / clase_extra). Se cobra por asistencia.
  • Volver a marcar asistencia no duplica la deuda. Pero desmarcar la asistencia no borra una deuda ya generada.
  • Las deudas pueden ajustarse (cambiar el monto, incluso a 0) desde facturación. Montos negativos no están permitidos.

Cómo se aplican los pagos y el saldo a favor

  • El pago se aplica a la deuda pendiente más antigua del alumno (o a una deuda puntual si se elige).
  • Si el monto cubre la deuda → queda pagada; si cubre parte → queda parcial.
  • Si el pago supera la deuda, el excedente pasa a saldo a favor del alumno.
  • El saldo a favor se descuenta automáticamente de la próxima deuda que se le genere al alumno; la profe también puede usarlo como pago manual.
  • El balance mostrado en todo el sistema es deuda − saldo a favor (si da negativo se muestra en verde "a favor").

Postulaciones

  • El alumno solo puede cancelar su postulación si está pendiente. Una vez respondida (aceptada/lista de espera), no.
  • Tras cancelar o ser rechazado, puede volver a postularse a la misma clase.
  • "Rechazar" a un candidato lo manda a lista de espera (no se borra: puede entrar si se libera un cupo y la profe lo acepta).

Alumnos

  • Un alumno desactivado no puede ingresar al sistema.
  • Desde su cuenta, el alumno solo edita nombre y teléfono y cambia su contraseña (email y nivel los maneja la profe).
  • La profe/admin puede resetear la contraseña de un alumno desde Alumnos (sin pedir la actual).
  • Al cambiar el nivel de un alumno, el sistema informa las clases futuras con nivel discrepante (solo aviso, no modifica).
  • El alumno no puede ver las deudas/pagos de otros alumnos.

Apertura de mes y liberación de cupos

  • Abrir mes cierra los meses anteriores y abre el nuevo; lista a los alumnos que no pagaron.
  • Liberar cupos saca al alumno deudor de todas las clases fijas del mes, pero no anula sus deudas: quedan pendientes para revisar/cobrar manualmente.

Reglas técnicas

  • Esquema en español: todas las tablas, columnas y valores ENUM en castellano. El backend traduce a claves JSON en inglés solo en las respuestas.
  • Plantilla de respaldo: las clases abiertas/extras se guardan con una plantilla inactiva de respaldo (la columna plantilla_id es obligatoria). Esa plantilla no genera clases recurrentes.
  • Borrar una clase elimina su plantilla de respaldo y, en cascada, sus grupos, inscripciones, asistencias y postulaciones. Las deudas NO se borran (pierden la referencia a la clase pero siguen existiendo).
  • Desactivar plantilla cancela las instancias futuras (quedan como historial, no se eliminan).
  • Generar mes es seguro de repetir (idempotente): no crea instancias duplicadas.
  • Horarios: el día de la semana se maneja como 0=Lunes … 6=Domingo internamente.
  • Autenticación: sesión de 7 días mediante cookie segura; roles verificados en el backend por cada ruta.

Operación y verificación (notas técnicas para la profesora/desarrollador)

Después de una actualización

  • El sitio se actualiza solo al subir cambios a main (frontend por GitHub Actions, backend por Render).
  • Si algo "se ve viejo" tras una actualización, hacer recarga forzada (Ctrl+F5 en la computadora) o abrir en una ventana de incógnito: el navegador puede estar usando una versión cacheada.

Verificación sin pruebas automáticas

  • Backend: node --check por archivo y arrancar node server.js.
  • Frontend: npm.cmd run build (en Windows, npm.ps1 está bloqueado por la política de ejecución → usar npm.cmd).
  • Los flujos contra la base de datos real se prueban en el sitio publicado.
